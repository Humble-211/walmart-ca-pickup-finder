Restock monitor

Telegram

The monitor sends restock alerts through a Telegram bot. Create one with BotFather, then message your bot once so it is allowed to reply to you.

The token is stored in this extension's storage. Other extensions cannot read it, but anyone with access to this Chrome profile on disk can.

Checking

A check has to come from a tab on the retailer's own site, so the monitor keeps one background tab open per watched retailer. It never reloads an existing tab, so a page you are in the middle of using is safe from it.

Watchlist

Nothing is being watched. Paste a product URL in the popup and press "Watch for restock".
